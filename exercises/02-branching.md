# Exercise 2: Branching

This is Exercise 2 of the hands-on Git workshop. It focuses on branch work:

- `git branch` to list branches
- `git checkout -b` / `git switch -c` to create and switch to a new branch
- `git merge` to combine branches
- `git branch -d` to clean up merged branches

Create a `student-exercises` branch, make changes on it, and merge back to demonstrate the flow.
